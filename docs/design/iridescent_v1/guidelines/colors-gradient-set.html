Primary — actions
--gradient-primary · teal → royal · buttons, active nav, focus ring. White text only clears 4.5:1 past the royal half — labels sitting over the teal end take ink.
Secondary — emphasis
--gradient-secondary · violet → magenta · primary-button hover end, avatar rings, highlight cards. Holds white text across the whole run.
Tertiary — data accent
--gradient-tertiary · --status-good-fill → --watch · chart bands, progress fills, in-range meters. Both ends are light: ink text only, never white.

tertiary alternate

cool
--gradient-tertiary-cool · teal → lime. Keeps tertiary inside the brand's cool half instead of borrowing the status palette, so a chart fill never reads as a "watch" state.
